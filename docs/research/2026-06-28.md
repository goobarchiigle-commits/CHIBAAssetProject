## 根本分析

### 旧 Study40〜46 の「高 ΔCAGR」は何だったか？

**原因1: Baseline も Feature も同じ intersection バグを持っていた**
→ 両ケースが 2020-08-11 からの短縮期間で計算されていた
→ ΔCAGR の相対値は「intersection 期間内での差」であり、正確には測定されていた

**原因2: WF Fold1 OOS 2020 の corona ショック除外**
→ 旧環境: Seg1 OOS 2020 は 2020-08-11〜2020-12-31 (corona 後半のみ)
→ 新環境: Seg1 OOS 2020 は 2020-01-01〜2020-12-31 (corona 全体)
→ corona 前半(2020-02〜04, -16.9% DD)が OOS に含まれると CAGR が下がり baseline が低下
→ 旧環境では baseline が「corona 後」のみで高かったため、feature の上乗せが大きく見えた

**結論**: 旧 +6.07pp WF ΔCAGR は intersection バグと corona 除外の二重効果によるもの。正確な環境では +1.37pp (E_COMBINED) が実態。

### 重要な発見

1. **EQ_SCALE (D) が Seg3_2022 を改善**: -5.11% → -2.65% (+2.46pp)
   - 熊市でのアドオン規律が DD 軽減に寄与している
   - IS全体でのCAGRは低下するが、最悪ドローダウン期を和らげる

2. **E_COMBINED WF 5/5**: Baseline 4/5 → E_COMBINED 5/5
   - 2022年弱気市場 (Seg3) を初めてパスさせた唯一のケース

3. **ATR_EXT の OOS 2025 パフォーマンス**: +13.87% vs Baseline +11.64% (+2.23pp)
   - OOS では最も有効だが IS での ΔCAGR は +0.18pp に過ぎない

4. **VOL_ADJ の OOS 2025 が Baseline 下回る**: 10.68% vs 11.64% (-0.96pp)
   - 2025年は calm 日比率が高く max_pos=4 の恩恵が裏目に出ている可能性
