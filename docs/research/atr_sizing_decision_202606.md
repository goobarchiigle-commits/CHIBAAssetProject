**重要な発見（U字型）**: 期待値はATR%に対して単調増加ではなく**U字型**。Q1（最低ATR%）とQ4（最高ATR%）が中間群(Q2/Q3)を大きく上回り、Q1がQ4よりわずかに高い（PF3.766 vs 3.129、寄与+8.48% vs +7.75%）。

この事実がB(現行ATR sizing)の構造的弱点を説明する: `position ∝ 1/ATR`の式では、**Q1(低ATR)は元々サイズが大きく付き(qty_capで頭打ち)、Q4(高ATR)だけが選択的に強く縮小される**。結果として、高期待値群のうちQ4側のみが減殺され、ポートフォリオ全体の期待値が損なわれる。前回診断(`atr_sizing_diagnostic_202606.md`)の「勝ちトレードの方がATR%高い→縮小率も高い」という発見と整合する。

## STEP4: 最終判定

```
decision = REMOVE
reason = A_EQUAL(均等配分)がB(現行ATR Sizing)に対しCAGR(+19.8% vs +10.4%)/Sharpe(0.798 vs 0.713)/PF(2.420 vs 2.020)の全指標で優位。E_NO_ATRも同様に全指標で優位(CAGR+15.2%/Sharpe0.753/PF2.339)。ATR感度を弱めたC/D(SQRT/0.25)はBよりCAGRがさらに低下し、判定B(弱化)条件を満たさない。
confidence = HIGH
```

判定基準（事前定義、機械的判定）:
- 判定A(維持): B が A に対し Sharpe または Calmar で+0.05以上の明確改善 → **不成立**（B-A: Sharpe-0.085 / Calmar-0.379、いずれも逆方向）
- 判定B(弱化): C または D が B に対し CAGR と Sharpe を同時改善 → **不成立**（C: CAGR-0.6pp / D: CAGR-1.0pp、いずれもCAGR悪化）
- 判定C(廃止): A または E が B に対し CAGR・Sharpe・PF の全てで優位 → **成立**（A・E両方が全指標で優位、二重に成立 → confidence=HIGH）

## 解釈

`position ∝ 1/ATR`という現行ATR Sizingの設計思想は、本戦略（ブレイクアウト系・高ボラ＝高期待値構造）と構造的に不整合。理由は単純な"risk_pctが低すぎた"ではなく（risk_pct感度分析で2.50-5.00%まで上げても解消せず）、**ATR四分位がU字型の期待値分布を持つため、ATRに反比例するサイジングは高ATR側の高期待値トレードを選択的に縮小してしまう**ことにある。ATR指数を弱める（C/D）対応も、低ATR側（Q1）まで一緒に縮小してしまうため逆効果。E(ATR完全無視・cap直接)が中間的改善を示すことも、「ATRに応じた縮小自体」が損失要因であることを裏付ける。

ATR Sizingの廃止（Equal Weight復帰、または将来的にE方式=cap直接採用）が定量的に支持される。次段階の対応（具体的な置き換え方式の選定）はWF実施前提の別タスクとして扱う。
