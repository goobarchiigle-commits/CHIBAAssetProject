# 日本株モメンタム — 完全新規アーキテクチャ 5案 — 2026-07-03

**前提**: Study01〜73全結果を拘束条件とする。既存Production改善・既存設計空間（FUJIKO-R含むクロスセクショナル・ロングオンリー・大型株日次回転）は対象外。
**設計原理**: 閉鎖領域の3つの壁（①自銘柄日足OHLCV由来の情報天井 IC≤0.14 [Study60] ②BWサンプル不足 [Study69] ③¥3M lot粒度 [Study25/44]）は微調整では越えられない。よって各案は**情報源・収益方向・商品・ユニバース・時間構造のいずれか1軸以上を根本から変える**。

| 案 | 変える軸 | 一言 |
|---|---|---|
| A | **収益方向**（ショート追加・β除去） | モメンタム・スプレッドMN |
| B | **情報源**（価格履歴→企業イベント） | 決算ドリフト(PEAD)モメンタム |
| C | **商品**（現物個別株→先物/ETF） | 指数タイムシリーズ・モメンタム |
| D | **情報源**（自市場→海外市場） | クロスマーケット・リードラグ |
| E | **ユニバース**（大型→グロース小型） | 小資本アクセスエッジ・モメンタム |

**共通前提**: 全案がsurvivorship-freeデータを要求 → **J-Quants API取得がStudy75と全5案の共通基盤**（1投資で6用途）。検証ゲートは既存規律を継承: WF5fold ∧ 2022非悪化 ∧ Bootstrap P(>0)≥95% ∧ コストストレス。

## ARCH-A: モメンタム・スプレッドMN（ロング/ショート・マーケットニュートラル）

**構造**: 貸借銘柄ユニバースをモメンタムランキング → 上位decileロング / 下位decileショート、金額ニュートラル。週次リバランス・信用取引。

- **エッジ仮説**: モメンタム情報は分布の下半分（弱者の継続下落）にも対称に存在する。現行系は分布の半分しか収穫していない。アンダーリアクション+処分効果は両方向に働く。β≈0のため**収益源が地合いから独立**し、現行が構造的にゼロ収益の2018-19横ばい・2022ベア（Study Regime分析の最弱2環境）でスプレッドは生き残る。
- **期待される市場環境**: クロスセクション分散が高い環境全般。ベア・横ばいで現行比の相対優位が最大。最悪環境=モメンタムクラッシュ（2020/3型の急激な弱者反発）。
- **弱点**: ①モメンタムクラッシュでL/S同時逆行（左テール太い）②逆日歩・貸株料・信用金利でコスト構造が現物の2倍超 ③ショート可能=貸借銘柄限定でユニバース半減 ④追証・強制決済の運用リスク。
- **検証方法**: J-Quantsでdecileスプレッド日次系列を構築（ショート実装不要・純データ分析）→ WF5fold + 2016/2020クラッシュ期ストレス + 貸借フィルター後再計測 + 逆日歩ストレス(-2%/年一律控除)。**研究コストは低い（実装コストと分離できる）**。
- **必要データ**: J-Quants（株価・上場廃止込み・貸借区分）。逆日歩履歴は近似ストレスで代替可。
- **実装難易度**: **高**（ショート執行・建玉/追証管理が新規。既存reconciliation/fail-closedランタイムは流用可）。
- **30%への理論経路**: スプレッド素α 8-12%（文献レンジ・要実測）× 信用レバ2-2.5x = 16-30%。**β=0によりDDが市場暴落と非連動→レバがCalmar制約と衝突しない、5案中唯一の構造**。CAGR30%∧Calmar1.5の同時成立に理論経路を持つ唯一の案。

## ARCH-B: 決算ドリフト・モメンタム（PEAD / イベントドリブン）

**構造**: トリガー=価格でなく情報イベント（決算サプライズ・上方修正・増配・自社株買い）。発表翌営業日寄付エントリー、保有日数事前固定（例40d）+災害ストップのみ。

- **エッジ仮説**: 決算後ドリフト（PEAD）— ポジティブサプライズへの反応は発表後20-60日継続する。日本はアナリストカバレッジの薄い中型で特に強い（情報拡散が遅い）。シグナル源が価格履歴の外にあるため**Study60のIC天井（価格由来特徴量）の外側**。エッジの経済根拠（アンカリング・注意制約）が文献で明文化済み — 現行系に欠けていた「Why this edge exists」を最初から持つ。
- **期待される市場環境**: 決算集中期（年4回）に収益集中。地合い依存は弱いが、ベアでは正サプライズの絶対数が減る。
- **弱点**: ①イベント数の季節性→資本回転に谷 ②サプライズ定義にコンセンサス必要（中小型は欠損→会社予想比で代替、定義の自由度=スヌーピング債務）③発表時刻（場中/引後）の処理を誤ると**即リーク**（発表日時の分単位データ必須）④初動ギャップで期待値の一部が取れない。
- **検証方法**: イベントスタディ（発表日時→翌営業日寄付固定でCAR曲線）→ 保有日数・サプライズ閾値は事前固定の少数グリッドのみ（bounded sweep）→ WF5fold。リーク検査: 発表日時の時刻精度監査を先行実施。
- **必要データ**: J-Quants（決算発表日時・財務諸表・会社予想）+ TDnet適時開示（修正・増配・自社株買い）。
- **実装難易度**: 中〜高（イベントパイプライン新規。執行系・現物口座は現行流用）。
- **30%への理論経路**: イベント当たり純期待値+1.5〜3%（40d・コスト後）× 年間採択30-50件 × 3-4スロット回転 = 20-35%。資本回転率がレバの代替になる（現物のみで到達可能性あり）。現行と収益源が独立→併走時の分散効果も取れる。

## ARCH-C: 指数タイムシリーズ・モメンタム（先物/ETFレイヤー）

**構造**: 日経225マイクロ先物・TOPIX先物（+セクターETF数本）の自己モメンタム（20/60/120d）でロング/ショート/フラットを日次判定。個別株を持たない。

- **エッジ仮説**: 単一資産の時系列モメンタム（Moskowitz型TSMOM）。個別銘柄αではなく市場βのタイミングを収穫。**Study25/44の壁（lot粒度・¥3M制約）が制度的に消滅**する — マイクロ先物は証拠金数万円で分割可能、ショートに逆日歩なし。
- **期待される市場環境**: 数週間〜数ヶ月続くトレンド（2013, 2023-24型）。最悪=往復レンジ（2018-19型）でのwhipsawコスト。
- **弱点**: ①クロスセクション分散が存在しない（銘柄選択αゼロ）②文献Sharpe 0.6-1.0で個別株モメンタムより低い ③レンジ期の期待値は負 ④先物口座の追加開設・別枠証拠金管理。
- **検証方法**: 指数40年分の日足で固定少数ルールグリッド→WF。**データ量が個別株研究の10倍以上あり、統計力は5案中最強**。ロールコスト実測補正必須。
- **必要データ**: 指数先物日足（ロール調整済）。無料圏（Stooq等）+ J-Quants指数で代替可。
- **実装難易度**: **低**（対象1-3銘柄・毎日1判定・既存ランタイムほぼ不要。kabuステーションAPI先物対応）。
- **30%への理論経路**: 単独ではvol-target 20-25%運用でCAGR15-25%が上限圏。ただし**証拠金効率により現物と資本を共有できる**（現物¥3M運用の傍らで証拠金¥30-60万のレイヤー追加）→「現物12% + 先物レイヤー10-15%」の**合算経路**。単独30%ではなくポートフォリオ部品。

## ARCH-D: クロスマーケット・リードラグ（海外→日本 情報拡散モメンタム）

**構造**: 米国セクターETF・ADR・USDJPY・CME日経先物夜間のオーバーナイト動向 → 日本の同業個別銘柄の翌日寄付エントリー・1-3日保有。

- **エッジ仮説**: 東京市場は米セッションの業種・個別情報を寄付で不完全にしか織り込まない（リードラグ / 情報拡散の遅延）。情報源が自市場の外→**Study60天井の外側**。日足運用制約と完全整合（シグナルは米引け後に確定、執行は翌東京寄付）。
- **期待される市場環境**: 米国主導のトレンド相場・米決算シーズン。日本独自材料主導の相場では効かない。
- **弱点**: ①エッジ持続1-3日→回転率極大→**コスト0.155%×高回転が最大の敵**（コスト後生存が最大の関門）②HFT/裁定業者と直接競合しdecayが速い ③ADR-現物マッピングの維持コスト ④エッジ実在の事前確率が5案中最低。
- **検証方法**: 米ETF/ADR前日リターン→日本個別の翌日寄付→翌々日寄付リターンの予測ICをsurvivorship-freeで測定。**生存条件を事前固定: IC>0.05 ∧ コスト後期待値>0。未達なら即殺**（1-2週間で白黒がつく=安く殺せる）。
- **必要データ**: 米国ETF/ADR日足（無料圏）、USDJPY、CME日経夜間、J-Quants現物。
- **実装難易度**: 中（データ統合が本体。執行は現行と同じ翌日寄付でランタイム全流用）。
- **30%への理論経路**: 成立すれば日次独立ベット多数→Sharpe 2超も理論上可→高レバ許容。ただし成立の事前確率<30%。**期待値の主成分はオプション価値**（安い検証コストで大きな上振れを買う宝くじ）。

## ARCH-E: グロース市場スモールキャップ・モメンタム（小資本=エッジ）

**構造**: ユニバースを東証グロース市場+スタンダード小型（日次売買代金¥50-300M帯）に置換。ランキング・回転技術は既存を流用、コストモデルとユニバースだけ差し替え。

- **エッジ仮説**: 機関投資家は流動性制約でこの帯域を買えない。¥3Mなら参加率5%以下で執行可能 — **Study15が弱点と認定した「資本の小ささ」をアクセスエッジに反転させる**。小型株のクロスセクション分散は大型の2-3倍→同じランキング技術でα密度が構造的に高い。個人資金フローのモメンタム増幅も追い風。
- **期待される市場環境**: リスクオン・個人資金流入期（2020-21, 2023-24）。最悪=金利上昇グロース売り（2022型で-30〜50%級DDの現実的可能性）。
- **弱点**: ①DD構造がCalmar目標と正面衝突（Calmar1.5は絶望的、1.0も困難）②ストップ高/安・特買い特売りで執行不能日が発生（BT/live parityの新しい敵）③スリッページ0.1%では済まない（0.3-0.5%ストレス必須）④survivorship影響が大型の数倍→**廃止込みデータなしでは検証自体が無効**。
- **検証方法**: J-Quants（グロース全銘柄・廃止込み必須）に既存Clenow型ランキングをそのまま適用、スリッページ0.5%・値幅制限モデル込みでWF + 2022ゲート。**既存検証インフラの流用率が5案中最大**。
- **必要データ**: J-Quants（グロース/スタンダード全銘柄・上場廃止込み・売買代金）。
- **実装難易度**: 低〜中（ユニバース定義とコストモデル差し替えが本体）。
- **30%への理論経路**: 小型モメンタムの素αは大型の1.5-2.5倍（分散比+文献）→ **5案中唯一、レバなし・現物・現口座のままCAGR 20-35%圏に理論到達**。代償はDD — 「30%は取れるがCalmar1.5は捨てる」トレードオフの明示的選択になる。

## Chief Architect 統合判断

1. **共通ボトルネック=データ**。J-Quants取得はStudy75+全5案の前提。これが次の一手（口座・APIプラン選定はASK_FIRST）。
2. **検証順序（研究コスト×情報価値順）**: ①**A**（decileスプレッド計測=純データ分析・実装不要で最重要の構造情報が取れる）→ ②**E**（インフラ流用最大・最速で30%到達可否が見える）→ ③**B**（発表日時データ品質監査から）→ ④**C**（並行可・最安）→ ⑤**D**（1-2週間のkillテストのみ。延命禁止）。
3. **目標との整合**: CAGR30%∧Calmar1.5の**同時**成立に理論経路を持つのはAのみ（β除去がレバとCalmarの衝突を解消）。Eは「30%を取りCalmarを捨てる」、Bは「25%前後で両指標中庸」の選択肢。**Final Architecture Review の目標改定結論は不変** — ただしAのスプレッドα実測が8%超なら、30%/1.5の再挑戦に唯一の実証根拠が生まれる。
4. **禁止事項の再確認**: 5案のどれも既存Productionの部品交換ではない。既存系とのハイブリッド化・パラメータ共有は各案の検証が独立で白になるまで禁止（3エッジ混載の再演を防ぐ）。
