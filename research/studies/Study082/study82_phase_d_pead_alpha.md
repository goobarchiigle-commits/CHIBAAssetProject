## 2. Positive / Negative サプライズ群の実測（40日後・コスト調整後）

| 指標 | Positive群 | Negative群 |
|---|---|---|
| イベント数 | 17,959件 | 12,993件 |
| 年間イベント数 | 1,943.6件/年 | 1,406.1件/年 |
| 平均raw return（40d） | +0.929% | +1.467% |
| **平均コスト調整後return（40d）** | **+0.619%** | **+1.157%** |
| 標準誤差 | 0.117% | 0.147% |
| **t統計量** | **5.3** | **7.9** |
| 勝率 | 49.4% | 51.6% |

**両群とも統計的に強く有意（t=5.3・7.9）**——「シグナルがない」のではない。ただし方向が古典的PEAD理論の逆——**Negative群（悪材料）の方がPositive群（好材料）より40日後リターンが高い**。

## 3. PEADスプレッド・CAGR推定・TOPIX比較

```
PEADスプレッド（Positive − Negative、コスト調整後）= -0.538%   ← 負（逆転）
単一スロットCAGR推定（Positiveのみ・年6.3サイクル複利） = +3.96%
（参考: Negative単独の同一annualization = +7.52%）
TOPIX基準CAGR（同一期間・単純B&H） = +12.76%
```

**注記（Study101との数値差異）**: 本StudyのTOPIX基準値（+12.76%）はTOPIX.parquet全期間（2016-2026）の単純CAGRであり、Study101のIS/OOS分割値（IS+5.92%/OOS+24.21%）とは算出方法が異なる。両者は矛盾ではなく別定義——混同しないこと。

Positive群単独でもNegative群単独でも、TOPIX単純B&Hに届かない。

## 5. 重要な副次所見：古典的PEADではなく「逆張り」パターン

**これは「シグナルなし」という結果ではない**。両群ともt統計量5-8台という強い有意性を示しており、**業績サプライズ後に統計的に頑健なリターン差が存在する**——ただし符号が古典的PEAD理論（好材料→継続的上昇ドリフト）の逆。実際には**悪材料決算の方が40日後リターンが高い**という平均回帰型のパターンが観測された。

**既存内部知見との整合性（単発の異常値ではないことの傍証）**:
- Study95（CS momentum factor-level）: 12-1モメンタムは6M/12Mで有意に負（弱い逆転）——過去の勝者が将来最下位
- Study99（Sector×Fujiko filter）: RS高パーセンタイル群は単調に悪化
- Study83（TSMOM）: トレンドフォロー実装は高turnoverでwhipsaw・負のリターン

**本Study82 Phase Dの結果はこれら3件と方向性が完全に一致**——「価格・業績の勢い」に賭ける継続型シグナルはこのデータセット・期間では軒並み逆転しており、単発の測定誤差ではなく複数独立手法にまたがる頑健な傾向として記録する。

## 7. 実装上の注記（限定事項・正直な開示）

1. **価格調整**: AdjustmentFactor（分割調整）は未適用（生Close使用）。保有期間中に日次リターン±40%を超えるイベントは分割等のコーポレートアクション疑いとして除外する固定ガードで部分的に緩和。
2. **サプライズ定義**: YoY EPS変化の符号のみ（2群分類）。パーセンタイル・標準化SUE等の高度化は「最適化」に該当するため実施していない——本結果は最も単純な定義での測定である点に留意。
3. **エントリータイミング**: 発表の場中/引後を区別せず一律「翌営業日始値」。Study82 Phase0で確認済みの`DiscTime`実測精度を本Studyでは活用していない（最小実装としての単純化）。
4. **実装トラブルとその対処**（透明性のため記録）: 初回収集はJ-Quants APIのレート制限（429）に持続的に抵触し、リトライ失敗を空リストとして誤ってキャッシュする実装上の欠陥があった。84件の汚染疑いキャッシュを削除し、スロットリングを1.2秒/リクエストへ変更・失敗と空データを区別する設計へ修正した上で全銘柄を再収集した（失敗0件で完走）。
