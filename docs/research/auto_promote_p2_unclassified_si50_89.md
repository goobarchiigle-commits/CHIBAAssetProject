## 2. P2 ゲート定義

```python
# P2 gate: UNCLASSIFIED candidates with 50 <= sector_ignition < 90
def gate_p2(rsr, si, comp):
    if rsr < 8.0:                              # Gate 1: RSR足切
        return False
    ctype = classify(rsr, si, comp)
    if ctype != "UNCLASSIFIED":                # Gate 2: taxonomy (UNC以外全拒否)
        return False
    if si < 50.0:                              # Gate 3-a: SI下限
        return False
    if si >= 90.0:                             # Gate 3-b: SI上限 (Case Dとの差異)
        return False
    return True
```

通過条件: **RSR≥8 AND type=UNCLASSIFIED AND 50≤SI<90**

## 11. 研究設計上の注意点（独立性の限界）

P2 仮説は Case E OOS 分析から帰納的に導出された:
1. Case E WF 実行 → UNCLASSIFIED成分 OOS +3.23% を観測
2. SI=50-89帯から来ると分析 → P2 定義
3. P2 を同じ OOS データで WF 検証

この設計には **確証バイアス (HARKing)** のリスクがある:
- P2 の WF は内部的に lookahead-free
- だが gate パラメータ自体が同一 OOS期間の観察から選ばれた
- 本当の独立検証は **2025年の前向きデータ** が必要

**これが 採用推奨 ではなく 追加研究推奨 とする主な理由**（下記 §12 参照）。
