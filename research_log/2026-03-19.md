## entry_stop v6 開発・凍結決定（2026-03-19）

**スクリプト**: `backtest/portfolio_entry_stop_v6.py`（新規）
**対象**: TEMPORAL 24銘柄ユニバース（2018-2024）

### 開発の経緯

v5 フル 1x でZ-score誤発火（DD=-0.45%でWARNING）が判明。`dd_abs>1%` 下限フィルターを追加したv6を実装・反復改善した。

#### 実装した機能一覧

| 機能 | バリアント | 実装内容 |
|---|---|---|
| 3条件Z-scoreトリガー | v6 | `z<-1.8 AND dd_abs>1% AND velocity<0` |
| 中央値ボラティリティフロア | v6b | `std_eff = max(std_raw, median(std_history))` |
| レジームゲート | v6c | `rolling_std>0.006 AND std_history_len>=252` でのみZ-score有効化 |
| 回帰ベースvelocity | v6c | `np.polyfit(20日equity)[0] / equity[-1]`（分率/日） |
| DD確認日数 | v6c | `dd_confirm_days=3`（自然ステージは3日連続で確定） |
| Exposure調整DD | v6d | `effective_dd = raw_dd / max(avg_exp_60d, 0.25)` |

#### 全バリアント結果

| バリアント | CAGR | Calmar | NORMAL% | avg_scale | 問題点 |
|---|---|---|---|---|---|
| ベースライン | +4.18% | 0.398 | 100% | 1.000 | — |
| v6（3条件） | -0.35% | -0.047 | 16.7% | — | std小さすぎ・誤発火継続 |
| v6b（中央値フロア） | -0.35% | -0.047 | 16.7% | — | bootstrap汚染（初期std_history≈0.002）|
| v6c（regime-gate） | -0.89% | -0.116 | 12.5% | 0.321 | 2018 velocity lock → 7年ロック |
| v6d（exposure調整DD） | -0.45% | -0.120 | 12.3% | 0.125 | ALERT 33x・ALERT%=85.8% |

#### 根本原因

```
TEMPORAL 2018年: avg_exposure = 0.082（91.8%キャッシュ）
→ portfolio DD = -3.7% は「リスク資産損失」ではなく「稼働不足による回復遅延」
→ velocity/z トリガー → WARNING → entry制限 → さらに稼働率低下 → 7年間WARNING継続
→ exposure調整（÷0.25）は逆効果: raw_dd-3.7% → effective_dd-14.97% → 即ALERT
```

年次 avg_exposure（TEMPORAL 1x）:
- 2018: 0.082 ← 根本原因
- 2019: 0.552 / 2020: 0.453 / 2021: 0.596 / 2022: 0.657 / 2023: 0.684 / 2024: 0.574
- 全体: 0.510

### 最終決定: entry_stop を TEMPORAL 1x で完全凍結

**根拠**: entry_stop は十分にデプロイされたポートフォリオ向けのツール。TEMPORAL 1x の低稼働率（初期 avg_exposure=0.082）は前提条件を満たさず、全4バリアントがベースラインを大幅下回った。

**再評価条件**: avg_exposure > 0.45 が安定維持される Phase 3以降

### 診断: 問題は2層構造

**層1: 市場環境（外因）**
2025年2-4月に3ヶ月連続マイナス。2025-04-02トランプ関税ショック（Liberation Day）によるTOPIX急落。TEMPORAL24の主力セクター（化学・電機精密・商社）が直撃。

**層2: CBデッドロック（内因・既知問題）**
CB有り vs CB無しの差: -11.70% vs -6.99% = **-4.71%がデッドロックコスト**。
2025-04-24 に DD -15.3% でCB発動 → 5月以降の回復相場に参加不可。
TOP2_SEC（2026-03-16に確認）と同じパターン。

### 重要な発見: RSRコンテキスト問題

**IS Sharpe: 0.387（今回）≠ 1.070（temporal_separation.py）**

原因:
- `portfolio_temporal_separation.py`: RSRをBIASED+TEMPORAL+TOP2の **~40銘柄**で計算
- `oos_2025.py`（実運用と同条件）: RSRをTEMPORAL24の **24銘柄のみ**で計算
- RSRはユニバース内相対ランク。銘柄数が変わるとmin_rsr=70の意味が変わる

**示唆**: 実運用に最も近い条件のIS性能はSharpe≈0.387。
研究_state.mdのSharpe=1.07はRSRコンテキストが広い条件（40銘柄）での値。
