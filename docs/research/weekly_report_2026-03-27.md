## 今週の主な技術実装

### 1. CBデッドロックバグ修正（最重要）

**問題**: `-15% DD` で CB 発動後、永続ロック状態になる構造バグ
```python
# 旧（バグ）: 毎日上書き = 回復不能
cb_active = dd < -MAX_DD_LIMIT

# 新（修正済み）: 状態機械
if not cb_active:
    if dd <= -MAX_DD_LIMIT:
        cb_active, cb_days = True, 0
else:
    cb_days += 1
    if cb_days >= 30 or dd > -0.05:  # 30日 or 回復で解除
        cb_active, cb_days = False, 0
```
**効果**: STEP2 CAGR が 1.5% → 13.9% に回復（6年間の実質停止が解消）
