**全3ケースで電機精密 100% が継続。セクター制約はセクター集中を解消しない。**

## 6. 制約効果の詳細分析

### 6-1. E1 (最大2/チェックポイント)

2022年の影響が最大：

```
P2-A 2022: 6920.T fwd30=+2.81% (n=3), 8035.T fwd30=+0.02% (n=3) → ΔCAGR=+3.16pp
E1   2022: 6920.T fwd30=-4.33% (n=3), 8035.T fwd30=-6.07% (n=2) → ΔCAGR=+0.30pp
```

E1の2022でブロックされた2件は、同チェックポイントに3〜4銘柄が同時に通過した月の「第3位・第4位（RSR順）」銘柄。  
ブロックされた候補の代わりに残った候補のうち、6920.T・8035.T の実現リターンが悪化している。  
**RSR優先でブロック対象を選ぶ際、高RSR ≠ 高fwd30 という事実が顕在化**。

### 6-2. E2 (最大1/チェックポイント)

2021改善・2022悪化の二面性:

**2021 (改善):**
```
P2-A: n=4  6146.T(-10.0%)×2, 6857.T(-5.1%), 8035.T(-1.0%) → ΔCAGR=-2.56pp
E2:   n=2  6857.T(-5.1%),    8035.T(-1.0%)                → ΔCAGR=-0.61pp
```
6146.T（最悪 -10.0%）が2チェックポイントともブロックされた結果、損失が大幅縮小。  
ただし「6146.Tが悪い」という情報はOOS時点では不知であり、結果論的な改善。

**2022 (悪化):**
```
P2-A: n=10, fwd30=+3.61%, wr=70%  → ΔCAGR=+3.16pp
E2:   n=6,  fwd30=-1.02%, wr=67%  → ΔCAGR=-0.71pp
```
- 6920.T が2022全期間でブロックされ（n=0）、代わりに残った組合せが平均リターン低下
- 勝率は維持（67%）だが、利益の大きな昇格が除外された影響で平均が悪化

### 6-3. 制約強化のトレードオフ

```
E2 の効果:
  + 2021 min ΔCAGR: -2.56pp → -0.61pp (+1.95pp 改善)
  - 2022 ΔCAGR:     +3.16pp → -0.71pp (-3.87pp 悪化)
  ± std ΔCAGR:       5.07pp →  4.14pp (低減, ただしE2は2/4負フォールドで達成)
  - 昇格機会: 32件 → 17件 (47%削減)
  - 2022 WF合格: 不合格 (2/4正)
```

「悪いとき」のケアをしようとすると「良いとき」のフルキャプチャを失う。  
これは少数銘柄 (n=4) × 単一セクターの昇格プールでは避けられない構造的ジレンマ。

## 7. ブラッシュアップ：なぜ制約が機能しないか

### 7-1. 「セクター多様化制約」の前提が崩れている

セクター多様化制約が有効に機能するための前提:
1. 複数セクターの昇格候補が同時に存在すること
2. 高セクター集中によって実際にセクター連動リスクが顕在化していること

P2-A の現実:
- 前提①: **満たされない**（全候補が電機精密）
- 前提②: **部分的に顕在化**（2021は全銘柄が同期ネガティブ）

### 7-2. RSR優先によるブロック選択の問題

セクター制約でブロックする際に「RSR が最も低い銘柄を除外」する設計を採用した。  
しかし実際のデータでは RSR と fwd30 の相関が弱く、高RSR 銘柄が低RSR銘柄より好成績とは限らない。

```
2022年 電機精密 銘柄別 fwd30 vs RSR:
  高RSR: 6857.T → fwd30=+21.9% (良い、優先採用→正解)
  中RSR: 6146.T → fwd30=+1.9%  (可)
  中RSR: 6920.T → fwd30=+2.8%  (可、一部ブロック→損)
  低RSR: 8035.T → fwd30=+0.0%  (中立)
```

RSR優先選択は「最悪候補を除外する」ではなく「RSR順に採用する」に過ぎない。

### 7-3. 本質的解決策は「ユニバース拡張」

セクター集中の根本解決には以下が必要:
- 他セクターの UNCLASSIFIED 候補（商社・銀行・化学等）を追加対象に
- SI≥50 かつ UNCLASSIFIED の条件を満たす非電機精密銘柄の実在確認
- 複数セクター候補が存在すれば、セクター制約が初めて「多様化効果」を発揮できる

## 8. 2021 改善シナリオの評価

E2のみ2021改善（-2.56pp → -0.61pp）。ただし：

```
2021改善の内訳 (E2):
  ブロック: 6146.T ×2件 (fwd30=-10.0%, -9.6%)
  採用:     6857.T ×1件 (fwd30=-5.1%)
            8035.T ×1件 (fwd30=-1.0%)
  改善幅: +1.95pp
```

「6146.T は最悪だったから除外で正解」という見方は**後出しバイアス**:
- 6146.T の除外はRSR優先で6857.T/8035.Tを採用した結果の偶然
- 6146.T の2022-2024 fwd30 は概ね正（+1.9%, +9.7%, +26.5%）
- 2021失敗は 6146.T 固有でなく4銘柄全体の構造的問題

かつ E2 は 2022 で -0.71pp（WF FAIL）。「2021だけ改善して2022を壊す」交換は採用不可。

4. E1/E2 と電機精密集中度は同じ（100%）→制約の意義なし

## 10. 電機精密集中リスクへの推奨対処

セクター集中は**管理すべきリスク**であることに変わりないが、解決は制約ではなくユニバース設計で行う：

| アプローチ | 実装コスト | 効果 |
|-----------|-----------|------|
| **チェックポイント制限 (E1/E2)** ← 本研究 | 低 | **無効（全候補が同セクター）** |
| **対象ユニバース拡張** | 中 | 有効（前提：他セクター候補の存在） |
| **昇格配分の上限設定 (ALLOC_MUL削減)** | 低 | リスク低減（リターンも低下） |
| **セクター ETF ヘッジ（証拠金・コスト）** | 高 | 除外 |

推奨: **P2-D（2025前向きテスト）で P2-A 本来の期待値を検証し、並行して非電機精密 UNCLASSIFIED 候補の存在確認を行う（P2-F仮）**
