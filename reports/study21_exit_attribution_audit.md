**観測ウィンドウ**: 2018-01-01 → 2025-12-31  (全完了トレード, lookahead=20営業日)

**Research Question**: 現行ExitはProfit tailを保持しつつリスク制御機構として機能しているか？

---
## Methodology（定義）

- `tail_capture` = actual_return / max_future_profit（勝ちトレードのみ定義）
  - max_future_profit = max(actual_return, entry→exit+20d 区間の最大ゲイン)
  - 負けトレードはprofit tailが存在しないため tail_capture=None（集計から除外、loss_avoided_ratioで評価）
- `profit_left` = counterfactual_max_gain（exit後20d以内に残っていた上昇余地、負値は0扱い）
- `loss_avoided_ratio` = future_loss_after_exit / max_future_loss
  - future_loss_after_exit = exit後20d以内に実際に発生した下落（exitで回避できた分）
  - max_future_loss = entry→exit+20d 区間で発生しえた最大下落（entry比）
  - 注: 分子はexit価格基準、分母はentry価格基準のため、exit時点で含み益が大きいトレードではloss_avoided_ratio>100%になり得る（exit後の戻しがentry比の最悪下落より大きい場合。算出エラーではない）
- `exit_quality_score` = 0.5×tail_capture + 0.5×loss_avoided_ratio（両方定義されている場合）
- `counterfactual_stop_breach_R` = exit後にholdを継続した場合の最悪R（entry基準, R_UNIT=2%）
- `early_exit_cost` = 全トレード平均のprofit_left（早すぎるExitで失った上昇）
- `late_exit_cost` = 全トレード平均のlate_exit_giveback = max(0, in_trade_MFE - actual_return)（Exit前にpeakから戻された分 = 遅すぎるExitのコスト）
- 反事実パスはraw close（slippage/commission未適用の理論パス）。実際の約定はSLIPPAGE/COMMISSION適用済み。

**Restrictions**: REPLACE_EXIT prohibited. Exit redesignはここでは提案しない。
