# 2026-03-22 研究ログ

## 実施内容

### 1. min_rsr 感度分析（rsr_sensitivity.py）
- スイープ: min_rsr = 60 / 65 / 70 / 75 × V2固定設定（29銘柄/均等/max3）
- 追加: max_positions=4（min_rsr=70固定）との比較

**結果:**
| min_rsr | CAGR% | Calmar | avg_exp | efficiency | zero_exp% |
|---------|-------|--------|---------|------------|-----------|
| 60 | +14.16 | 1.271 | 0.357 | 0.396 | 18.0% |
| 65 | +15.11 | 1.422 | 0.349 | 0.433 | 17.9% |
| 70 | +15.50 | 1.516 | 0.336 | 0.461 | 18.6% |
| **75** | **+16.51** | **1.796** | **0.327** | **0.504** | **19.1%** |
| 70+max4 | +14.94 | 1.349 | 0.308 | 0.485 | 19.4% |

**発見:** RSRを締めるほど全指標が改善。RSR=75が最良。max_positions=4は悪化。

### 2. min_sepa 感度分析 + エントリーファンネル診断（sepa_sensitivity.py）
- RSR=75固定、min_sepa = 3/4/5/6
- 週次サンプリングでファンネル構造を計測

**ファンネル結果:**
```
Universe(16銘柄) → RSR通過(6.22) → SEPA通過(5.81〜6.21) → シグナル(0.40/日)
```

**重要な発見:**
- SEPAフィルターは93〜100%を通過させる（ボトルネックではない）
- 本物のボトルネック: RSRモメンタム + Turtleブレイクアウト（SEPA通過後の6〜7%のみ通過）
- zero_exp≈18%は下降相場での意図的な待機（Feature、バグではない）
- min_sepa=3/4/5のバックテスト結果は完全一致 → sepa=6がわずかに最良

**確定:** sepa=6が最適（他と同等以上、変更不要）

### 3. Step3 最終バックテスト + OOS検証（step3_final_validation.py）
- 確定設定: RSR=75 / sepa=6 / max_positions=3 / 均等ウェイト / 29銘柄
- WF: 2年IS + 1年OOS × 5セグメント（2020〜2024 OOS）
- 年別分布・市場レジーム分析

**フル期間（2018-2024）:**
- CAGR=+16.51% / MaxDD=-9.19% / Calmar=1.796 / Sharpe=1.616

**WF結果（5セグメント）:**
- OOS負けセグメント: 0/5
- OOS平均Sharpe: 1.370 / IS平均: 1.538 → OOS/IS比=1.10（過学習なし）
- Fold2（OOS=2021）のみ ratio=0.07（avg_exp=0.073）→ WF手法の warmup制約による

**年別:**
- 負け年: 2018(-2.0%)のみ = 1/7 (14%) → 基準≤30%クリア

**レジーム耐性:**
- COVID暴落: -3.9%（軽微）→ COVID回復: +30.0%
- 2022ベア: +6.8%（生き残り ✅）
