## 5. 2021 Fold 詳細分析（核心的発見）

### 5-1. SI閾値は2021失敗に無効

```
P2-A (SI≥50): 2021 n=4, fwd30=-6.51%, wr=0%, ΔCAGR=-2.56pp
B1  (SI≥60): 2021 n=4, fwd30=-6.51%, wr=0%, ΔCAGR=-2.56pp  ← 完全一致
B2  (SI≥65): 2021 n=4, fwd30=-6.51%, wr=0%, ΔCAGR=-2.56pp  ← 完全一致
```

**3ケース全て2021 Fold で n=4, 同一銘柄, 同一結果。SI下限は2021失敗に無効。**

### 5-2. 2021 昇格の SI 実測値

```
2021 昇格銘柄  SI=72.4（4件全て同値）
              ↑
              SI≥50 ✓
              SI≥60 ✓
              SI≥65 ✓  ← B2でも通過する
              SI≥73 → 初めて排除できる
```

2021に昇格したのは SI=72.4 の銘柄のみ。これは50/60/65 どの閾値でも通過する。  
排除するには SI≥73 以上が必要だが——

### 5-3. タクソノミー制約との衝突（構造的問題）

| SI値 | RSR<85 の場合 | 分類 |
|:----:|:-------------|:----:|
| ≥75 | RSR<85 → EARLY_IGNITION | 対象外 |
| 72.4 | RSR<85 かつ SI<75 → UNCLASSIFIED | **通過** |
| <55 | RSR<55 → MEAN_REVERSION | 対象外 |

**UNCLASSIFIED が SI≥75 になりえない**: 生産環境タクソノミーで SI≥75 かつ RSR<85 は EARLY_IGNITION に分類される。そのため UNCLASSIFIED ゲートで SI≥75 を課しても、電機精密セクターの中位銘柄（RSR=70-84, SI=50-74）にのみ効果が出る。

→ **P2型ゲートで2021失敗を排除できるSI閾値は存在しない**。SI≥73〜74 なら理論上排除できるが、こうしたマジックナンバー的パラメータは過学習リスクが高く採用不可。

## 6. SI引き上げのコスト：有益な昇格の消失

### B1 (SI≥60) の昇格消失

```
P2-A n=32  vs  B1 n=14  → 18件消失
```

消失した18件の内訳（2023-2024集中）:
- 2023: P2-A n=8 → B1 n=3（5件消失）、P2-A fwd30=+9.84%
- 2024: P2-A n=10 → B1 n=0（10件全消失）、P2-A fwd30=+10.64%

→ **SI=50-59 の昇格群は好成績（2023-2024）だった**。これを除去すると実績が崩壊する。

### B2 (SI≥65) の枯渇

```
2023: n=0（完全枯渇）
2024: n=0（完全枯渇）
```

SI≥65 では 2023/2024 で昇格がゼロになる。高閾値は「フィルタ」ではなく「ゲート閉鎖」として機能している。

## 7. ブラッシュアップ: SI は「ゲート品質」ではなく「昇格機会数」を制御している

P2系ゲートにおける SI の役割を整理する：

| SI レンジ | 2021 含む？ | 有益昇格含む？ | 効果 |
|-----------|:----------:|:----------:|------|
| 50-59 | なし | **あり (2023-2024)** | 有益 |
| 60-72 | なし | **あり (2022-2023)** | 有益 |
| 72.4 | **2021 発火** | **2022-2024 発火** | 混在 |
| 73-89 | なし | 少量 | 機会損失 |

SI=72.4 は 2021 に「悪い昇格」として、2022-2024 に「良い昇格」としても現れる。  
SI値だけでは2021と2022-2024を識別できない。**2021固有の変数（相場レジーム）が主因**。
