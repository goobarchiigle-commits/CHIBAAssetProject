## 判定: DD増加の定量帰属

全体DD増加量: **+3.66pp**（A -15.7% → C -19.4%）

| 帰属先 | 寄与(pp) | 割合 | 判定 |
|---|---|---|---|
| **A: 動的ユニバース** | -2.54pp | **69.4%** | **主因** |
| E: その他（sizing existing→equal切替） | -0.86pp | 23.5% | 副因 |
| C: Exit変更（ATR Trailing+MultiRSR+MTF合計） | -0.26pp | 7.1% | 軽微 |
| B: 集中化 | -- | -- | **反証**（4指標全てがCの方が低集中度を示し、不支持） |
| D: 特定年度 | -- | -- | **不支持**（2021/2023悪化 vs 2020/2024/2026改善、双方向で単一年度に帰属不可） |

```
primary_cause = A（動的ユニバース）
secondary_cause = E（sizing existing→equal切替）
rejected = B（集中化: ポートフォリオ指標で反証）, D（特定年度: 年別が双方向で不成立）
confidence = HIGH（feature isolation waterfallとポートフォリオ指標が一致して同方向を示す）
```

## 解釈

DD増加の約7割は**動的ユニバース機能（bear市場でのセクター除外＋RSR再選定）そのものが持つ構造的トレードオフ**に起因する。Study33で確認した通りUniverseはCAGR/Sharpeを明確に改善する（ΔCAGR+0.77pp/ΔSharpe+0.055）真のアルファ源泉であり、**DD増加とリターン改善は同一機能から同時に生じている**（リスク・リターンのトレードオフであり、不具合や設計ミスではない）。残り約24%はsizing_mode切替（equal weight化によるexposure増31.0%→35.2%）に起因し、これもStudy33・Study32で確認済みの「Equal Weightがリターン・Sharpe双方を改善する」効果の裏面（ボラティリティ増加）である。Exit変更（ATR Trailing/Multi-layer RSR/MTF）はDD・リターンともに実質的に無関係（Study33で確認済みのMulti-layer RSRのゼロ寄与と整合）。

**結論**: DD増加は「悪化」ではなく、CAGR・Sharpe改善と表裏一体の構造的リスクテイク増加（Universe機能の地合い感応性＋Equal Weightサイジングのexposure増）であり、新ベースラインC_PROD_MINUS_ATR（Calmar1.020、A:1.026とほぼ同値）はリスク調整後で見ればAPRIL_REPROと実質同等の効率性を維持している。
