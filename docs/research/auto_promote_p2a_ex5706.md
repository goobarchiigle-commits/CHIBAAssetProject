## 9. ブラッシュアップ：P2研究全体への示唆

### 9-1. 2021 失敗は 5706.T の問題ではない

5706.T除外で -3.73pp → -2.50pp に改善（+1.23pp）するが、**2021 FAIL は構造的に継続**する。

```
2021 P2-A n=4: 6146.T=-10.0%, 6857.T=-5.1%, 8035.T=-1.0%, 6920.T=ゼロ
```

全銘柄が同方向にネガティブ。これは：  
- 2021年4月〜6月：コロナ相場のピーク→横ばい転換  
- SI=50-73 という「部分点火」が市場転換期に集中  
- セクター全体の同期下落（電機精密）  

**SI下限引き上げ（P2-B: SI≥60 or ≥65）またはレジームフィルターが2021対策に有効**

### 9-2. 電機精密セクター集中リスク

P2-A 4銘柄 **全員が電機精密セクター**。

| 銘柄 | セクター |
|------|---------|
| 6146.T | 電機精密 |
| 6857.T | 電機精密 |
| 6920.T | 電機精密 |
| 8035.T | 電機精密 |

SI計算はセクター平均ベース → **同一セクターの銘柄は同じSI値を持つ**。  
すなわち「4銘柄 UNCLASSIFIED + 50≤SI<90」は実質「電機精密セクターが中程度点火している局面で、RSR=85-89の銘柄群を昇格する」条件。  
最悪ケース: MAX_POS=3 の全スロットが電機精密に埋まる。

→ **P2系ゲートにはセクター多様化制約の追加を検討すること（同一セクター最大1スロット）**

### 9-3. 6857.T の alpha 依存と研究上のリスク

6857.T（東京エレクトロン）が P2-A ΔCAGR の 64% を生成。  
これは「6857.T が UNCLASSIFIED帯に落ちてくるタイミング（RSR=85-89）を正確に捕捉できている」ことを示す一方：

- OOS サンプル数 n=6（4年間で6件のみ）
- 2025年以降のサイクル転換で有効性が変化するリスク  
- P2 仮説は Case E OOS から帰納的に導出 → 独立性が不完全

### 9-4. P2-A の「実効alpha」見積もり

Leave-two-out 最弱シナリオ（excl 6857.T+6146.T）= +1.11pp は、**ゲートが機能しなくなる最低ライン**。  
実際の期待値を保守的に見れば：

```
ΔCAGR 期待値 = weighted average:
  [6857.T在籍年] +5.38pp × P(6857.T昇格) + [不在年] +1.5pp × P(不在)
```

これはP2系ゲートの「再現可能な底上げ効果」が +1〜2pp 程度であることを示唆。  
+5.38pp という数字は 6857.T × 2023 半導体ブームの偶然の一致に大きく依存している可能性がある。

## 12. 最終判定

### ▶ 採用推奨 / 追加研究推奨 / 棄却

## **追加研究推奨**

### 理由

**PASS**: 全WF指標は基準値を超過。P2より微改善（+5.38pp vs +5.12pp）。LOO最弱シナリオでも正。

**懸念**: 
1. **2021 Fold失敗継続** (-2.50pp): 5706.T除外後も2021は全銘柄負 → 構造的問題
2. **6857.T 過依存** (64%寄与): 半導体サイクル依存の単銘柄リスク / OOS n=6
3. **電機精密 100% 集中**: 4銘柄全員が同セクター → ポートフォリオ多様化を毀損
4. **独立性限界**: P2仮説はCase E OOS観察から帰納的導出

### 次ステップ

**P2-B（最優先）**: SI下限を60または65に引き上げて2021 Fold改善を試みる  
**P2-E（並行検討）**: セクター多様化制約（同セクター最大1スロット）追加  

5706.T除外は正解だが、P2-Aは採用に十分な独立性・堅牢性をまだ持たない。
