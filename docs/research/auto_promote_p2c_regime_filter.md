P2-A の 2021 Fold 失敗（ΔCAGR=-2.56pp, 勝率0%）が「相場転換局面」への集中が原因かを検証。

## 7. 2021 Fold 深掘り分析（核心的発見）

### 7-1. 各フィルターの2021効果

```
P2-A (フィルターなし): n=4  fwd30=-6.51%  wr=0%  ΔCAGR=-2.56pp
C1 (RSR<40禁止)     : n=4  fwd30=-6.51%  wr=0%  ΔCAGR=-2.56pp  ← 改善ゼロ
C2 (RSR<50禁止)     : n=2  fwd30=-7.34%  wr=0%  ΔCAGR=-1.50pp  ← 部分改善のみ
C3 (50<200MA禁止)   : n=4  fwd30=-6.51%  wr=0%  ΔCAGR=-2.56pp  ← 改善ゼロ
C4 (20d ret<0禁止)  : n=4  fwd30=-6.51%  wr=0%  ΔCAGR=-2.56pp  ← 改善ゼロ
```

### 7-2. なぜフィルターが効かないか

2021年の昇格は **全て「正常相場」に見える局面で発生**した：

| 2021昇格条件 | C1(RSR≥40?) | C2(RSR≥50?) | C3(MA50>200?) | C4(ret20≥0?) |
|:---:|:---:|:---:|:---:|:---:|
| RSR=65.5 (Jan/Feb) | ✓ | ✓ | ✓ | ✓(+9.3%) |
| RSR=58.6 (Mar) | ✓ | ✓ | ✓ | ✓(+0.5%) |
| RSR=48.3 (Apr) | ✓ | **✗** | ✓ | ✓(+1.7%) |

- C2のみ一部ブロック（RSR<50の月）。ただし残り2件も負継続。
- C1は RSR<40 が2021全月で一度も発生しないため完全無効。
- C3は 50MA>200MA が年間通じて維持されたため完全無効。
- C4は昇格月の20日リターンが正のため完全無効。

### 7-3. 2021失敗の本質

**TOPIX市場指標が「健全」を示している中で電機精密セクターが先行下落した**。

```
2021年4月-6月の電機精密 (UNCLASSIFIED zone):
  - 昇格月: RSR=48-58（中位水準）
  - TOPIX RSR: 44-66（正常域）
  - 昇格後30日: 全銘柄 -1% 〜 -10%（セクター個別要因）
```

マーケット全体指標（RSR / MA / 20d ret）が「昇格OK」を示す中での「セクター内先行下落」が原因。  
TOPIX ベースのレジームフィルターではこの構造を捉えられない。

## 8. C1〜C4 各フィルターの構造的問題

### C1 (TOPIX RSR<40 禁止)

- 2021: 無効（RSR最低=41.4、一度も<40に到達せず）  
- 2022: 全ブロック（ただし2022はP2-A平均+3.16ppの有益Fold）→ 最大の機会損失  
- 2024: 若干フィルタリング（8件/10件通過）でΔCAGR+9.96pp（P2-Aより+1.3pp改善）  
- **結論**: 有益な2022昇格を完全に潰す。正フォールド 2/4 → **REJECT**

### C2 (TOPIX RSR<50 禁止)

- 2021: 2件ブロック（限定改善のみ、残り2件も負継続）  
- 2022/2023: 全件または大半をブロック → 事実上「昇格停止」  
- 合計 n=5 のみ（P2-A比84%削減） → 統計的に無意味  
- **結論**: 過剰抑制。期待値マイナス。**REJECT**

### C3 (50MA<200MA 禁止)

- 2021: 完全無効（年間デスクロスなし）  
- 2022: 14件ブロック（Fold+3.16pp → +0.00ppに壊滅）  
- 2023/2024: 影響なし（ゴールデンクロス維持）  
- **結論**: 2022年の有益昇格を過剰ブロック。正フォールド 2/4 → **REJECT**

### C4 (20日リターン<0 禁止)

- 2021: 完全無効（昇格月は全て20d ret > 0）  
- 2022: 2件のみブロック（ほぼ影響なし）→ Fold改善 +3.16→+3.84pp  
- 2023: 影響なし  
- 2024: 8件ブロック → Fold低下 +8.66→+5.10pp（有益昇格を一部除外）  
- std削減: 5.07→4.27pp (−16%)  
- **総合**: ALL PASS。ただし P2-Aより-0.72pp劣位、2021改善ゼロ

## 9. ブラッシュアップ：レジームフィルターの役割の限界

### 9-1. 「市場レジーム vs セクターレジーム」問題

本研究で示された根本的矛盾:

```
P2-A ゲートの失敗タイプ:
  2021: TOPIX正常 × 電機精密下落 → 「セクター先行弱体化」
  理論的対策: セクター別RSRトレンド / 電機精密専用フィルター
  ×TOPIX広域フィルター (C1-C4)
```

TOPIX等重指数が「正常」を示している時に、電機精密セクターだけが先行してピークアウトするパターンは TOPIX指標では検出不可能。

### 9-2. C4の「ノイズ削減」効果は副作用

C4(20日リターン<0)がPASSした理由:
- 2022弱気相場では20d ret<0が頻発 → 2022の昇格を自然にフィルタリング（結果的に有益）
- 2024は20d ret<0が一時的 → 一部の有益昇格を除外（コスト発生）
- 2021: 昇格月が全て20d ret>0 → フィルター無効

C4は「相場の短期下落中に昇格しない」という合理的なルールだが:
- 2021の失敗原因は「昇格後の長期下落」であり「昇格時の短期下落」ではない
- 2024の機会損失 (-3.56pp) が2022の利益 (+0.68pp) を大幅に上回る

### 9-3. 正しい次の研究方向

| アプローチ | 期待効果 | 検討理由 |
|-----------|---------|---------|
| **セクター RSR フィルター** | 電機精密 RSR<50 で昇格停止 | 2021問題の実根因 |
| **TOPIX フィルター廃止** | シンプル化 | C1-C4全てが2021を改善しない |
| **P2-E セクター分散制約** | 電機精密1スロット上限 | 集中リスク緩和（後続研究）|

| C2 (RSR<50) | -0.47pp | -0.016 | REJECT | 限定的 | — |

### ▶ 推奨: **フィルターなし（P2-A 維持）**

**理由**:

1. **2021失敗はTOPIX系フィルターで解決できない構造的問題**  
   C1/C3/C4 は2021の4件全てを通過させる（TOPIX指標が正常を示すため）。  
   C2 のみ2件削減するが残り2件が依然負で改善は限定的、かつ全体期待値が大幅悪化。

2. **フィルター追加は有益昇格の機会損失を生む**  
   C1は2022年の+3.16pp相当の昇格機会を完全消失。C3も同様。  
   P2-A が最高の期待値を維持している。

3. **C4はPASSだが最適ではない**  
   2021改善なし、avg ΔCAGR -0.72pp、2024機会損失-3.56pp。  
   「変動を抑制したい」場合の次善策として留保するにとどめる。
