## 4. 勝ち/負けトレード群集計（高ATR=高期待値仮説の検証）

| 指標 | 勝ちトレード(n=155) | 負けトレード(n=125) |
|---|---|---|
| 平均ATR20（円、価格非正規化） | 187.1 | 203.9 |
| **平均ATR%（ATR20/価格、正規化済み）** | **10.35%** | **9.39%** |
| 平均エントリー価格 | ¥2,366 | ¥2,700 |
| 平均APRILサイズ | ¥630,413 | ¥626,147 |
| 平均ATRサイズ | ¥392,351 | ¥430,255 |
| 平均サイズ縮小率 | **35.1%** | 28.5% |
| 平均利益率 | +7.8% | -4.3% |

**重要な訂正**: 価格非正規化の生ATR（円）だけを見ると勝ち(187.1)<負け(203.9)で「負けの方が高ATR」に見えるが、これは勝ちトレードの方が平均エントリー価格が低い（¥2,366 vs ¥2,700）ことに起因する見せかけの逆転である。**ATRを価格で正規化したATR%（実際にサイジング式 qty=risk÷ATR_yen が反応する「相対ボラティリティ」）で見ると、勝ちトレードの方が明確に高ボラ（10.35% vs 9.39%、+10.2%関係比）**。

この結果、ATRサイジングは**勝ちトレードを平均35.1%、負けトレードを平均28.5%縮小**しており、**勝ちトレードの方が約6.6pt多く縮小される**。すなわち：

```
高ATR%銘柄 → サイズ縮小（多） → 実際に高期待値（勝率+利益率とも優位） → CAGR/Sharpe低下
```

という仮説は**本データで支持される**。本戦略は`research_state.md`記載のStudy27（2026-06-21、Heat Budget検証）で既に「本戦略のボラティリティはリスクではなくアルファの発生局面（vol=alpha signature）」と独立に確認済みであり、本診断結果はその過去の発見と整合する。

## 6. 最終判定

### 判定: **B（ATR Risk Sizingがこの戦略と構造的に相性が悪く、サイジング式自体の見直しが妥当）。ただしAの要素（risk_pctの再調整自体は有効）も併存する。**

**Bを支持する定量根拠**:
1. **勝ちトレードの平均ATR%（10.35%）が負けトレード（9.39%）より高い**——本戦略の「ボラティリティ＝アルファ」という構造的特性が確認された（Study27の既存発見と整合）。
2. その結果、**ATRサイジングは勝ちトレードを負けトレードより多く縮小**（35.1% vs 28.5%）——リスク管理の意図（高ボラ＝高リスクだから縮小）が、この戦略では逆にアルファの大きい方を選択的に削る方向に働く。
3. **risk_pctを4倍（1.25%→5.00%）にしてもAPRIL_REPRO水準（CAGR16.1%）に到達しない**（5.00%時点で14.6%、-1.5pp）。これは単純な「risk_pctが低すぎた」（Aのみ）では説明できない——`qty_cap=capital×25%`という別の固定キャップが並走しており、risk_pctを上げるほど多くのトレードがこのキャップに飽和し、ATRによる差別化そのものが意味を失っていく（risk_pctを上げ続ければ理論上は全トレードがキャップ一定値に収束し、結果的に「ATRサイジングを使わない」状態に近づくのみ）。

**Aの要素も部分的に支持**: risk_pct=1.25%→2.50%でCAGR/Sharpe/Calmar/PF全指標が改善することは前回感度分析で確認済みであり、**現行1.25%が最適から離れていること自体は事実**。「risk_pctの再調整」は短期的な改善手段として有効。

**総合結論**: risk_pctの調整だけでは構造的な収益性回復に限界がある（B）。同時に、現行1.25%は明らかに過度に保守的であり、調整自体は無駄ではない（A）。次段階としては、**risk_pctの単純な引き上げではなく、「ボラティリティが高い＝この戦略ではむしろポジティブシグナル」という前提に立ったサイジング式自体の再設計**（例: ATRに対して逆比例ではなく、ATR%とRSR/モメンタムの複合スコアで配分するなど）を検討する価値がある。risk_pct単独のWalk-Forward検証（前回提案）は実施する価値があるが、**それだけでは本質的な解決にならない可能性が高いことを前提として進めるべき**。

```
final_verdict = B（構造的相性問題、優位）+ A（calibration不足、副次的）
key_evidence  = winners_atr_pct(10.35%) > losers_atr_pct(9.39%)
              = winners_size_reduction(35.1%) > losers_size_reduction(28.5%)
              = risk_pct 4倍化でも未収束（CAGR -1.5pp残存 @5.00%）
              = avg_exposure飽和（qty_cap=25%との競合、2.50%以降プラトー）
confidence    = HIGH（全項目コード実測、推測なし）
next_step     = サイジング式の再設計検討（risk_pct単純調整のWF検証は実施するが本質解ではない可能性を明示）
```
