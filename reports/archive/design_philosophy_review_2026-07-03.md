## 1. Universe思想

| 判定 | 内容 |
|---|---|
| 一致 | モメンタムランキング型ユニバース（Clenow/IBD直系）。Bear時セクター除外はClenowの「指数フィルター時のみ買う」思想の拡張形 |
| **矛盾** | **Chanが第3章で最初に問う2点（survivorship-free? data-snooping?）に両方NO**。RSR42はin-sample選定＝Fitschenの「バスケット全体で機能しない戦略はカーブフィット」原則に正面衝突。42銘柄でのパーセンタイルは粒度2.4pt/銘柄 → RSR75/70という閾値の有効数字が思想的に成立しない |
| 改善 | ルールベース再構築（流動性フィルター付きTOPIX500等、上場廃止込み）。「銘柄を選んだ」から「選定規則を検証した」への転換。Study75として提案済み |

## 2. Entry思想

| 判定 | 内容 |
|---|---|
| 一致 | 原版はMinervini SEPAトレンドテンプレート+Link的「複数条件の合流を待つ」思想+タートル機械的トリガーの教科書的実装。個々は正統 |
| **矛盾** | **3つの異なるエッジ理論の無自覚な積層**。Minervini=成長株の個別テンプレート、タートル=ブレイクアウトの統計的優位、Clenow=クロスセクショナル相対強度回転。「勝つ理由」が違う→「負ける理由」も違うのに失敗モード設計は未分化。Chan基準では各フィルターが統計的に稼ぎを証明する義務があるが、Study54実測IC<0.065＝**積層は測定可能なアルファを加えていない** |
| 改善 | 単一パラダイムへの純化実験。最有力=Clenow純正型（週次回転・ブレイクアウトトリガー廃止・ランクのみ）をベンチマークWFとして走らせ「複雑性は稼ぎに見合ったか」を1本で回答 |

## 3. Exit思想

| 判定 | 内容 |
|---|---|
| 一致 | ATRトレイリングはタートル/Clenow正典。Fitschen第5章の手仕舞い類型（損切り/時間/利食い/トレイル）を全種実装済みという意味では網羅的 |
| **矛盾** | **最重度**。Fitschenの思想は「類型を比較テストし、システムの性格に合う1つを選ぶ」。Productionは7系統をOR結合し、ATR Extension（RSR Exitの発火を遅らせるパッチ）で**ルール同士を戦わせている**＝band-aidルールの典型。Study65実測でBigWinnerの80%がピーク前にRSR系Exitで切られる＝**トレンドフォローの存在理由（テール捕獲）をExit層が構造的に否定**。Linkの「損は切り、利は伸ばせ」の後半が死んでいる |
| 改善 | Exit哲学の一本化: 災害ストップ+トレイル（タートル型）か、ランク脱落回転（Clenow型）の二択。Study67 Case_C（BW=Keep/非BW=Replace）が既にこの方向の実証を持つ |

## 4. Risk思想

## 5. Position Sizing思想

| 判定 | 内容 |
|---|---|
| 一致 | EQ_SCALE addon=タートルのユニット追加/Minerviniの増し玉と同思想（勝ちにのみ加える）。均等ウェイト自体はChanなら「正当化されていれば可」 |
| **矛盾** | Carver/Clenowの正典=ボラ正規化サイジングを明示的に放棄（vol_target=0, use_idm=false）。ただしStudy25が「¥3Mではlot丸めがvol-sizingのアルファを破壊する」を実証済み→無知ではなく制約。**真の思想矛盾は上流**: Chan第2章「Your Trading Capital」は資本に合う戦略を選べと説くが、本プロジェクトは機関投資家型の多層システムを¥3Mに載せた＝**設計様式と資本規模の不一致** |
| 改善 | 二択を明示: 資本を設計に合わせる（Study74=¥20-30M再検証）か、設計を資本に合わせる（層を削る）。中間は両方の欠点を得る |

## 6. Capital Management思想

| 判定 | 内容 |
|---|---|
| 一致 | 段階的稼働（10%→Limited Live）はPenfoldのstart-small、Chanのpaper trading段階論と完全一致。half_kelly_cap=0.50はThorp→Chan系譜の正統。**この領域は書籍群と最も整合** |
| **矛盾** | 平均キャッシュ83%・exposure 29-36%で目標CAGR30% → **Penfoldの資金管理方程式（期待値×頻度×サイズ）が閉じていない**。Chan第2章「Your Goal」: 目標が戦略選択を規定すべきだが、本プログラムは目標と無関係なマイクロ研究に21本を投じた |
| 改善 | 方程式を先に解く: 必要CAGR = f(exposure, edge, frequency) を明示し、どの変数を動かすかを意思決定してから研究を配分する |

| # | 問題 | 主査読者 | 思想的核心 |
|---|---|---|---|
| 1 | **Exitがシステムの存在理由を否定** — BW80%早期切断。トレンドフォローを名乗りながらテールを自ら切除 | Link/Clenow | 「利を伸ばせ」の構造的違反 |
| 2 | **3エッジ理論の無自覚混載**（Minervini×Turtle×Clenow） — 勝つ理由が3つ=負け方の設計が不能 | Fitschen | エッジの単一性 |

## よりよい手法の模索（書籍思想に沿った検証可能候補）

1. **Clenow純正ベンチマークWF**（最優先・1本で#2/#6/#8に回答）: 週次回転・ランクのみ・MA200単一フィルター・トレイルなしの最簡構成 vs D_ATR_EQ。複雑性が+何ppを稼いだかを初めて定量化。負けたら層を削る根拠、勝ったら現行維持の根拠になる
2. **RoR計算**（即日可能・バックテスト不要）: 既存309トレード分布からモンテカルロで破産確率算出。Penfold基準の合格ラインを初めて持つ
3. **Exit二択実験**: 「災害ストップ+トレイルのみ」構成のWF。Study67の方向を思想レベルで完結させる
4. **ユニバース規則化**（Study75と同一）: 選定規則そのものをWF対象にする

1・3・4は新規スクリプト=ASK_FIRST。2は既存データの読み取り分析で即実行可能。
