構造的理由:
- UNCLASSIFIED = RSR=85-89 + 低compression (comp<28) で CONTINUATION を外れる「中間帯」
- この「中間帯」にいる銘柄は、セクター全体が強い (SI=100) 局面では大抵 MATURE_LEADER に昇格 (rsr≥87 + comp低下) か EARLY_IGNITION (SI高い = rsr<85 の別銘柄が支配)
- SI≥90に達する局面では、電機精密セクター全体が急騰 → シャドウ候補の多くはすでにLIVEユニバース入りか MATURE_LEADER に転落
- UNCLASSIFIED ≡ 「RSRが中途半端でセクター強度も平常時」の状態 → SI≥90と構造的に共存しにくい

> **UNCLASSIFIED + SI≥90 は設計上の矛盾**: セクター全体が強い(SI≥90)ときに、「RSRがHIGH_RSRに届かずCONTINUATIONにも入れない」銘柄が昇格してくるのは、実態として相場の強さに乗れていない銘柄を掴む行為に近い。

## 11. 根本原因分析

### Case D が Case A より悪化した理由

UNCLASSIFIED許可 + SI≥90 の組み合わせが機能しない構造的理由:

1. **論理的矛盾**: SI≥90（セクター全体強）のとき、RSR=85-89帯の銘柄は以下のいずれかに移行:
   - RSR≥90 → HIGH_RSR（許可済み）
   - RSR≥87 + comp<35 → MATURE_LEADER（ブロック）
   - SI≥75 + RSR<85 → EARLY_IGNITION（許可済み）
   - CONTINUATION（RSR≥70 + comp≥28 + RSR<88）
   - 残余 = 非常に狭い帯 → UNCLASSIFIED + SI≥90 は構造的に稀

2. **残余の品質**: 上記分類をすべて外れてUNCLASSIFIED になる銘柄は「RSRは高いが圧縮が低く、しかもHIGH_RSRに届かない」状態。セクターが全面強のときに、これらの銘柄は強さに乗り切れていない「中間帯の落ちこぼれ」になりやすい。

3. **実証値**: OOS 4年 × 5銘柄 × 12月 = 240評価のうち、UNCLASSIFIED + SI≥90 は**1件のみ** (0.4%)。この確率はサンプル不足を超えて構造的な発生困難を示す。

### Case E の UNCLASSIFIED成分 (+3.23%) との乖離

| 項目 | Case E UNCLASSIFIED | Case D UNCLASSIFIED |
|------|--------------------|--------------------|
| SI 閾値 | 50以上 | **90以上** |
| SI 実際値 (OOS) | 53〜100 | **100のみ** |
| n件数 | 32件 | **1件** |
| fwd30 平均 | +3.23% | **-9.54%** |
| 勝率 | 57% | **0%** |

Case EのUNCLASSIFIED成分 (+3.23%) の価値は **SI=50〜89帯**から来ていた。SI≥90を求めると、正期待値は消滅する。
