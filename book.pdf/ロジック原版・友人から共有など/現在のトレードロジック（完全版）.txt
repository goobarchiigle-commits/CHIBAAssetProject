現在のトレードロジック（完全版）                                                                                                                               
                                                                                                                                                                   ---                                                                                                                                                            
  第1層: 銘柄の「強さスコア」を計算する（RSR）                                                                                                                   

  計算式:
  RSR = 過去12ヶ月のリターンを加重平均してユニバース内で順位付け

    直近3ヶ月のリターン × 40%（重要度高）
  + 3〜6ヶ月前のリターン × 20%
  + 6〜9ヶ月前のリターン × 20%
  + 9〜12ヶ月前のリターン × 20%

  → 42銘柄の中で何番目に強いかをパーセンタイルで表す（0〜100）

  例: RSR=85 は「42銘柄のうち上位15%の強さ」

  ---
  第2層: SEPA 8条件スクリーニング

  8つの条件を毎日チェックし、何個満たしているか数える。6個以上でエントリー候補。

  ┌─────┬────────────────────────────────────────────────────┬──────────────────────────────┬───────────────────────────────────┐
  │  #  │                        条件                        │             意味             │             要するに              │
  ├─────┼────────────────────────────────────────────────────┼──────────────────────────────┼───────────────────────────────────┤
  │ C1  │ 株価 > 150日移動平均線 かつ 株価 > 200日移動平均線 │ 長期上昇トレンドの中にいる   │ 半年・1年の平均価格より上         │
  ├─────┼────────────────────────────────────────────────────┼──────────────────────────────┼───────────────────────────────────┤
  │ C2  │ 150日移動平均線 > 200日移動平均線                  │ 中期線が長期線を上回っている │ トレンドが整列している            │
  ├─────┼────────────────────────────────────────────────────┼──────────────────────────────┼───────────────────────────────────┤
  │ C3  │ 200日移動平均線が21日前より上                      │ 長期トレンド自体が上向き     │ 1ヶ月以上ずっと上昇中             │
  ├─────┼────────────────────────────────────────────────────┼──────────────────────────────┼───────────────────────────────────┤
  │ C4  │ 50日移動平均線が前日より上                         │ 短期トレンドが上向き         │ 直近2ヶ月の平均が今日も上がった   │
  ├─────┼────────────────────────────────────────────────────┼──────────────────────────────┼───────────────────────────────────┤
  │ C5  │ 株価 > 50日移動平均線                              │ 短期平均より上にいる         │ 直近2ヶ月の平均より今の株価が高い │
  ├─────┼────────────────────────────────────────────────────┼──────────────────────────────┼───────────────────────────────────┤
  │ C6  │ 株価 ≥ 過去1年最安値 × 1.30                        │ 底から30%以上回復している    │ 底値から十分に離れている          │
  ├─────┼────────────────────────────────────────────────────┼──────────────────────────────┼───────────────────────────────────┤
  │ C7  │ 株価 ≥ 過去1年最高値 × 0.75                        │ 高値から25%以内にいる        │ 高値圏に近い位置にいる            │
  ├─────┼────────────────────────────────────────────────────┼──────────────────────────────┼───────────────────────────────────┤
  │ C8  │ RSR ≥ 70                                           │ ユニバース内で上位30%以上    │ そもそも強い銘柄                  │
  └─────┴────────────────────────────────────────────────────┴──────────────────────────────┴───────────────────────────────────┘

  判定:
  - 8個 = キング（最強）
  - 6〜7個 = エース（買い候補）
  - 5個以下 = 除外

  ---
  第3層: 買いシグナルの最終チェック（全部必要）

  条件A: SEPA ≥ 6個（エース以上）
  条件B: RSR ≥ 75（上位25%以内）
  条件C: RSRモメンタムが「プラスかつ前日より増加」
          ※ RSRモメンタム = 今日のRSR - 21日前のRSR
          → 強さが加速しているかどうか
  条件D: 今日の株価が20日間の最高値を更新した
          ※ タートルズのブレイクアウト手法
          → 直近1ヶ月の天井を突き破った瞬間に買う

  全部満たした銘柄 → RSRが高い順に最大3銘柄まで購入

  ---
  第4層: 売りシグナル（どちらか1つで売り）

  売り①: RSRモメンタムがマイナス かつ 前日より悪化
          → 「強さが失われ、さらに弱まっている」
          ★ 2025年はほぼこれが発動（5日以内）

  売り②: 今日の株価が20日間の最安値を割り込んだ
          → タートルズの損切りライン

  ---
  第5層: ポートフォリオ管理ルール

  資本合計: 300万円
  同時保有数: 最大3銘柄
  1銘柄の上限: 75万円（資本の25%）
  残りはキャッシュで待機

  手数料: 0.055%（auカブコム）
  スリッページ（値ずれ): 0.1%
  → 1回の売買コスト合計 約0.155%

  ---
  第6層: 緊急ブレーキ（サーキットブレーカー）

  ポートフォリオ全体が -15% になった瞬間
  → 新規買い禁止（既存ポジションは保持）

  さらに -10% 進んで -25% になったら
  → 各ポジションの30%を強制売却

  ---
  セクター別の戦略切り替え

  同じ42銘柄でも、業種によって戦略を変える:

  ┌────────────────────────────────────────────────────┬──────────────────────────────┬────────────────────────────────────────────────────┐
  │                        業種                        │             戦略             │                        理由                        │
  ├────────────────────────────────────────────────────┼──────────────────────────────┼────────────────────────────────────────────────────┤
  │ 海運・機械・電機・商社・食品・医薬品・情報・不動産 │ フジコ法（上記のモメンタム） │ トレンドが出やすい成長業種                         │
  ├────────────────────────────────────────────────────┼──────────────────────────────┼────────────────────────────────────────────────────┤
  │ 銀行・保険・鉄鋼・ガス・化学・陸運・輸送機器・石油 │ 平均回帰法                   │ 景気循環で上下するため「下がりすぎたら戻る」が効く │
  └────────────────────────────────────────────────────┴──────────────────────────────┴────────────────────────────────────────────────────┘

  平均回帰法のロジック:
  買い: RSI(5日) < 25 かつ 200日移動平均線より上にいる
  売り: RSI(5日) > 65 または 保有7%損失 または 10日経過

  ---
  まとめ: 1日の流れ

  毎営業日の引け後に自動実行:

  1. 42銘柄の RSR を計算（42銘柄全体で順位付け）
  2. SEPA 8条件をチェック（何個クリアしているか）
  3. RSRモメンタムを確認（強さが増加中か）
  4. ブレイクアウト確認（20日高値を更新したか）
  5. 全条件を満たした銘柄 → 翌日の寄り付きで買い注文
  6. 既存保有銘柄の売り条件もチェック → 該当したら翌日売り
